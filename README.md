# nand-craft

A browser-based digital logic simulator and puzzle game. Build circuits from NAND gates, solve puzzles, and learn how computers work from the ground up.

### **[>>> Play online <<<](https://svinerus.github.io/nand-craft/)**

## Controls

See **[docs/controls.md](docs/controls.md)** — keyboard, mouse, sidebar, windows, the test
editor and the RAM window. That file is the single source: the game renders it under
**Controls** in the main menu, so it cannot drift from what the game does.
